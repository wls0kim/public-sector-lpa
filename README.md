# 세대 간 차이의 한계를 넘어: 잠재 프로파일 분석을 통한 공무원 조직의 재해석

## 개요

인적관리 연구에서 MZ세대를 하나의 동질적인 집단으로 보고 출생 연도로 나누어 분석하는 경우가 많습니다. 이 방식은 개인 간 차이를 지나치게 단순화하고, 세대에 대한 고정관념을 강화할 수 있습니다. 이 연구는 출생 연도 대신 공무원이 실제로 경험하는 조직, 직무, 직업 특성의 응답 패턴으로 하위 집단을 찾는 잠재 프로파일 분석(LPA)을 적용해, 공무원 인적관리의 대안적 접근을 제시했습니다.

## 자료

2023 공직생활실태조사 (N = 6,444). 원자료는 포함하지 않았습니다.

## 분석 절차

1. 이직의도에 영향을 미칠 수 있는 요인을 세 차원으로 나누고 차원별 척도 점수 계산
   - 조직 차원: 조직몰입, 조직문화 유형(과업, 혁신, 관계, 위계), 보상
   - 직무 차원: 공공봉사동기, 직무 자율성, 역할 갈등, 역할 모호성, 업무 과중
   - 직업 차원: 공직만족, 순환보직, 전문성, 공직 평판, 부패 인식
2. 차원별로 프로파일 수 2~4개 모형을 `tidyLPA`로 추정하고 정보 지수, 엔트로피, 집단별 인원을 비교해 최종 모형 선택
3. 프로파일별 척도 평균을 비교해 유형 해석
4. 프로파일별 연령 분포를 확인해 세대 구분과 프로파일이 일치하는지 검토
5. 프로파일에 따른 이직의도와 직무만족 차이를 분산분석으로 검증

- 실제 자료로 끝까지 실행해 확인했습니다. 점검 환경에 `tidyLPA`를 설치할 수 없어, 같은 모형(분산 동일, 공분산 0)을 `mclust`로 추정하는 대체 함수로 실행했습니다.
- 합치는 과정에서 생긴 결과 출력 오류(`print(n = Inf)`, `count()` 충돌)를 고쳤습니다. 모형 추정에는 영향이 없습니다.
